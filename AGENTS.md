# Project Rules
- Stack: React, TypeScript, Tailwind CSS, Vite.
- Source of truth: Figma MCP node data (exact spacing, typography, hex colors, border-radius).
- Do not invent placeholder content or generic gradients; extract real copy and assets from Figma.
- Keep components modular in `src/components/`.
- Responsive: desktop-first matching Figma frame width, clean mobile adaptation below 768px.
